Question on submit [function submitQ()]:
  - if Question is the first: previous button has display: none
  - if wrong: Correct option -> background green, Wrong option -> background red, correct-counter value stays as it is (does not decrease)
  - if right: Correct option -> background blue, correct-counter value decreases by 1 (wrong-counter = length - blue correct Questions)
  - after 2 seconds: redirects to the next json object Question automatically
  - During these 2 seconds: All options, Next, and Previous buttons are disabled (force poor user to wait), fronzen the entire page in this period

Selection & Clicking Logic:
  - Click option 1 -> background matches hover effect, next button transforms to modern green submit button
  - Click option 2 -> background matches hover, option 1 goes back to normal (remove semi-hover class)
  - Click option 2 again -> semi-hover class removed, submit button goes back to next button
  - Click option 2 -> click submit button -> run submitQ(), then setTimeout 2 seconds and redirect

Navigation Logic:
  - Previous click -> changes elements to the previous question data in JSON, showing their submitted results (if it was correct and option is blue, it displays as true when back to it)
  - Next click -> correct-counter value stays as it is (only changes elements)
  - correct-counter value decreases ONLY when submitting a correct answer
  - If a question is already submitted: options backgrounds are colored, you cannot change your answer, and hover effects are disabled
